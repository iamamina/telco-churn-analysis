# telco-churn-analysis
Анализ оттока клиентов телеком-компании и модель прогноза

## Цель проекта
Выявить факторы, которые влияют на уход клиентов телеком-оператора, и построить модель, оценивающую вероятность оттока для каждого клиента. 

## Данные
[Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn): 7 043 клиента, 21 признак.  
Информация о договоре, подключённых услугах, платежах и демографии клиента.

## Факторы оттока

| Признак | Высокий отток | Низкий отток |
|---|---|---|
| Тип контракта | помесячный — 43% | двухлетний — 3% |
| Интернет | оптоволокно — 42% | DSL — 19% |
| Техподдержка | нет — 42% | есть — 15% |
| Способ оплаты | electronic check — 45% | автоплатёж — 15–17% |

Отдельно выделяется сегмент **«помесячный контракт + оптоволокно»**: отток 55%, это 30% клиентской базы.

## Что сделано
1. **Подготовка данных.** Привела `TotalCharges` к числовому типу, заполнила пропуски (новые клиенты с нулевым стажем), закодировала категориальные признаки.
2. **Разведочный анализ.** Изучила отток в разрезе стажа, контракта, услуг, оплаты и демографии.
3. **Новые признаки:** `is_new_client`, `auto_payment`, `monthly_fiber`.
4. **Моделирование.** Сравнила Logistic Regression, Random Forest и Gradient Boosting на 5-фолдовой кросс-валидации с учётом дисбаланса классов.
5. **Оценка.** Проверила модель на тестовой выборке, построила матрицу ошибок, подобрала порог и оценила важность признаков.

## Сравнение моделей (кросс-валидация)

| Модель | Recall | Precision | ROC-AUC |
|---|---|---|---|
| Logistic Regression | 0.80 | 0.52 | 0.85 |
| Random Forest | 0.75 | 0.56 | 0.85 |
| Gradient Boosting | 0.52 | 0.66 | 0.85 |

Выбрана логистическая регрессия: такое же качество, но выше recall и проще интерпретировать.

## Рекомендации для бизнеса

2. Запустить программу удержания для клиентов в первые 12 месяцев.
3. Стимулировать подключение автоплатежа.
4. Проанализировать цену и качество оптоволоконного интернета.
5. Еженедельно передавать в отдел удержания список клиентов с высоким риском.

## Результаты
- Отток составляет **26.5%**, большая часть уходит в первый год обслуживания.
- Главный фактор — **помесячный контракт**.
- Модель (логистическая регрессия) находит **~80%** уходящих клиентов, **ROC-AUC 0.84**.
- Обзвон **20%** клиентов с самым высоким риском охватывает **49%** всех уходящих.
